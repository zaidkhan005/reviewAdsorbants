# Table 1. Condition-labelled comparison of selected target-material studies

**Scope and reading rule.** This main-text table covers 15 selected primary-study records from the active 49-work corpus. Panel A contains 19 endpoint entries because some papers report independent experiments or internally conflicting source values; repeated study IDs are intentional. Each row must be read as its own condition set. Panel B separates fitted models, reuse/recovery, matrix evidence and preparation/cost evidence. The table is not a universal capacity ranking. Supplementary Table S1 documents all 49 selected works.

**Notation:** CIP = ciprofloxacin; TC = tetracycline; TCH = tetracycline hydrochloride (kept distinct from TC); CTC/OTC/DTC = other tetracycline-class co-targets; GO = graphene oxide; rGO = reduced GO; SGO = sulfonated GO; CNF = cellulose nanofibril; GAC = granular activated carbon; PRB = permeable reactive barrier; NR = not reported or not available in the audited source record. “Derived” means calculated from stated concentration, volume, adsorbent mass and removal; it is not a source-tabulated measured qe. Fit outputs are never treated as observed uptake.

## Table notes

1. One row in Panel A represents one independent endpoint or one separately identified source result. Repeated candidate IDs do not imply duplicate studies.
2. The C0, dose, pH, temperature and time columns describe only the endpoint on that row. NR is used instead of importing a condition from another experiment in the same paper.
3. Source-reported observed qe, mass-balance-derived qe, percentage removal and model-fitted qe/qmax are different metrics. They must not be interchanged.
4. Mixture-level results are not assigned to an individual antibiotic unless the source supplies target-resolved values. TCH is not silently relabelled TC.
5. Recovery efficiency, removal retention and qe-capacity retention are distinct. A reported cycle percentage is not a capacity-retention percentage unless the source measures it that way.
6. A high fitted capacity, waste-derived precursor, magnetic separation or high removal percentage does not alone demonstrate low cost. The cost and preparation column records only what the source actually quantifies.
7. Table 1 is a condition-labelled main-text subset, not a leaderboard and not a substitute for the full 49-work Supplementary Table S1.
