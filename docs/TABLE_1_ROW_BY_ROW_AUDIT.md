## Table layout changes applied

1. Split study identity from condition sets and separated the evidence into nine lettered components. Recovery/regeneration is now displayed as two four-column panels (1F(a) method/cycle count; 1F(b) cycle performance/qualification), giving ten visible table panels overall.
2. Separated target, material, study context, condition vector, endpoint value and endpoint qualification.
3. Split recovery method, regeneration medium and cycle count into Table 1F(a); split cycle metric, result and qualification into Table 1F(b). This removes the previous seven-column squeeze. Matrix/feed, test type and validation limitation remain separate in Table 1G. Preparation burden and cost evidence remain independent.
4. Separated observed qe, derived qe, percentage removal, kinetic-model qe and isotherm qmax; the TC-specific SEM-040 SI value is not combined with the seven-drug mean.
5. Added the TC-specific SI result for SEM-040 (200.2202 µg/g); the seven-drug mean is retained only in narrative context, not as a TC endpoint.
6. Preserved the 49-work selection and the source access levels. This is a table-presentation and source-register reconciliation, not a screening change.
